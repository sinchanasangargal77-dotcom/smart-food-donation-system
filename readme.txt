# AI-Based Smart Food Waste Optimization System

This project helps restaurants donate leftover food to nearby NGOs, orphanages, and old-age homes using Machine Learning and location intelligence.

## Features
- Food donation analysis
- ML-based priority prediction
- Dynamic location support
- Nearest NGO recommendation
- Streamlit web application

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Geopy
